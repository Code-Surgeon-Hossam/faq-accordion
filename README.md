# FAQ Accordion

My solution to the [FAQ accordion challenge on Frontend Mentor](https://www.frontendmentor.io).

## Live Demo

https://code-surgeon-hossam.github.io/faq-accordion/

## Features

- Open and close each question with a click
- Only one answer open at a time
- Responsive layout (mobile and desktop)
- Keyboard accessible (Tab, Enter, Space) with visible focus styles
- Hover states for questions

## Built with

- Semantic HTML5
- CSS3 (Flexbox, media queries, custom fonts)
- Vanilla JavaScript
- ARIA attributes (`aria-expanded`, `aria-controls`)

## What I learned

- Why `<button>` inside `<h2>` is the right structure for an accordion
- How `aria-controls` connects a button to the content it controls
- How to toggle content with the `hidden` attribute
- How to reset default button styles (`font: inherit`)
